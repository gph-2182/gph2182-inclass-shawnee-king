1 Exercise 1: Continental Report Card (Cycle 1)

Summarize the global burden of child mortality by continent using gm.

# 1. From gm, keep 2008 rows with non-missing child_mortality
# 2. Group by continent
# 3. Summarize: mean_cm = mean(child_mortality), max_cm = max(child_mortality),
#    n_countries = n()
# 4. Arrange the result from highest to lowest mean_cm
gm |>
  filter(year == 2008, !is.na(child_mortality)) |>
  group_by(continent) |>
  summarize(mean_cm = mean(child_mortality), max_cm = max(child_mortality), n_countries = n()) |>
  arrange(desc(mean_cm))

A clinic network stores visits and lab results in separate tables.

visits <- tibble(

lab_results <- tibble(
  visit_id = c("V01", "V03", "V04", "V06"),

)

# 2. Use anti_join() to list the visits with NO lab result on file

visits |> left_join(lab_results, by = "visit_id") #6 rows, because every visit_id is kept when using left_join

4 Exercise 4: Integration Challenge + AI Corner (Cycle 4)

Which continents improved life expectancy the most between 1998 and 2008?

# Build ONE pipeline from gm that:
# 1. Keeps rows for years 1998 and 2008 (year %in% c(1998, 2008))
# 2. Drops rows missing life_expectancy (drop_na())
# 3. Groups by continent and year, then summarizes mean_le = mean(life_expectancy)
#    (use .groups = "drop")
# 4. Pivots wider: names_from = year, values_from = mean_le, names_prefix = "y"
# 5. Adds gain = y2008 - y1998 and arranges by gain, largest first
#
# AI Corner: ask your AI assistant the same question, then audit its answer.
# Does it filter the years? Handle NAs? Can you verify every verb it used?
gm |> filter(year %in% c(1998, 2008)) |>
      drop_na(life_expectancy) |>
      group_by(continent, year) |>
      summarize(mean_le = mean(life_expectancy), .groups = "drop") |>
      pivot_wider(names_from = "year", values_from = "mean_le", names_prefix = "y") |>
      mutate(gain = y2008 - y1998) |>
      arrange(desc(gain))
# A tibble: 6 × 4
  continent y1998 y2008  gain
  <chr>     <dbl> <dbl> <dbl>

3 Europe     74.9  77.5 2.51
