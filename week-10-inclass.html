3 Exercise 3: Monte Carlo: ER Surge Risk (Cycle 3)

An emergency room averages 6 arrivals per hour and can handle 9 per hour.

# 1. Write surge_hours(n_hours = 8, rate = 6, capacity = 9) that simulates ONE
#    shift with rpois(n_hours, lambda = rate) and returns the number of hours
#    whose arrivals are above capacity
# 2. After set.seed(2182), run 5,000 shifts with map_dbl() and store the results
# 3. Estimate (a) P(at least one surge hour in a shift) and
#    (b) the mean number of surge hours per shift
# 4. Compare with the exact answers:
#    (a) 1 - ppois(9, 6)^8   (b) 8 * (1 - ppois(9, 6))
#    How close is each estimate? What happens with only 100 shifts?
surge_hours <- 
  function (n_hours = 8, rate = 6, capacity = 9){
  arrivals <- rpois(n_hours, lambda = rate)
  sum(arrivals > capacity)
  }
set.seed(2182)
surges <- map_dbl(1:5000, ~ surge_hours())
mean(surges >= 1)
[1] 0.5008
mean(surges)
[1] 0.6692
1 - ppois(9,6)^8
[1] 0.5040339
8 * (1 - ppois(9,6))
[1] 0.6713921

4 Exercise 4: The Central Limit Theorem + AI Corner (Cycle 4)

Hospital length of stay is skewed: model it as exponential with a mean of 4 days (rate = 1 / 4).

# 1. After set.seed(2182), build a tibble with n = rep(c(2, 40), each = 2000)
#    and add xbar = the mean of n simulated stays, using map_dbl()
# 2. Draw a histogram of xbar faceted by n (facet_wrap(~ n, scales = "free"))
#    Which panel looks closer to a normal curve?
# 3. For each n, compare sd(xbar) with the theory value 4 / sqrt(n)
# 4. AI Corner: an AI wrote this to estimate the standard error of the mean of 40 stays:
#      sim_mean_los <- function(n = 40) {
#        set.seed(123)
#        mean(rexp(n, rate = 1 / 4))
#      }
#      se_ai <- sd(map_dbl(1:1000, \(i) sim_mean_los()))
#    Run it. What is wrong, and why? Write a fixed version that gives a sensible
#    standard error, and check that your 1,000 replicates are all different.
set.seed(2182)
sim <- tibble(n = rep(c(2, 40), each = 2000)) |>
        mutate(xbar = map_dbl(n, \(k) mean(rexp(k, rate = 1/4))))
ggplot(sim, aes(xbar)) +
  geom_histogram(bins = 40) +
  facet_wrap(~ n, scales = "free")
sim |>
  group_by(n) |>
  summarise(sd_sim = sd(xbar), sd_theory = 4/sqrt(first(n)))
# A tibble: 2 × 3
      n sd_sim sd_theory

2    40  0.650     0.632
